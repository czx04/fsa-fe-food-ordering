# Food Ordering


## Yêu cầu

- Node.js 20.19 trở lên (hoặc 22.12 trở lên)
- npm 10 trở lên
- MongoDB đang chạy local hoặc một MongoDB connection string

## Chạy local

```bash
./run.sh
```


- Frontend: http://localhost:5173
- Backend: http://localhost:3000
- Health check: http://localhost:3000/api/health
